# SmartCity Mobile - Tech Stack

## Core Technologies

- **React Native** `0.79.5` + **React** `19.0.0`
- **Expo** `~53.0` - Development platform
- **TypeScript** - Type-safe development

## Navigation & Routing

- **Expo Router** `~5.1` - File-based routing

## Styling & UI

- **NativeWind** `4.1` - Tailwind CSS for React Native
- **React Native Paper** `5.14` - Material Design components

## State & Data Management

- **Zustand** `5.0` - Lightweight state management
- **React Hook Form** `7.62` + **Zod** `4.0` - Form validation
- **Axios** `1.6` - HTTP client

## Key Features

- **React Native Maps** - Geolocation & mapping
- **Stripe React Native** - Payment processing
- **Expo AV & Video** - Media handling
- **Maestro** - End-to-end testing

## Platform Support

- Android | iOS | Web
